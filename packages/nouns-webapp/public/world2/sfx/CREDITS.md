# Noun World sound effects: credits and licences

Every file here is public domain (CC0 1.0,
https://creativecommons.org/publicdomain/zero/1.0/). Nothing is CC-BY, NC, ND
or "royalty-free". Credit isn't required by CC0; it's given anyway.

All files were transcoded to mono MP3 (44.1 kHz, 40–56 kbps) and peak-normalised
to -1 dBFS. The two wind files are 8 s excerpts (left channel) with fades; the
`ud-accent` file is the first 3.2 s with fades. Nothing else was edited.

Loaded by `src/miniapps/world2/audio/sfx/Sfx.ts` (lazily, on first use).
