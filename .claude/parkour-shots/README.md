# Parkour engine + NOUN PARKOUR: browser shots

Real Noun World (headless Chromium, SwiftShader, `?q=low`), driven through
`window.__w2` with the loop frozen and stepped at 60 Hz. Each move was set up in
the real city or on a route's course props, then framed from its own geometry.

- `desktop/gal-01…21-*.webp`: every move, 1280×800, HUD off: wall run, wall
  jump (twist), the other wall, wall up, hang, shimmy, pull up, precision jump,
  stuck landing, balance, pole swing / slide / launch, slide, vault, roll,
  stumble, hand-over-hand climb, mantle, gap jump, ledge leap.
- `desktop/hud-g*.webp`: THE GAUNTLET with the HUD on (timer, gate counter,
  next-gate arrow + hint, R / QUIT), `l1/l2`: LAMP LINE up the mast and the
  launch to the first lamp. `ui-*.webp`: results card and route menu.
- `desktop/remote-riders.webp`: two remote riders posed only from the `pk`
  key in their pose blobs (one hanging off the lip, one wall running),
  through Net's real ingest.
- `phone/*.webp`: 390×844 touch: countdown, HUD while wall running and
  hanging (DUCK / RUN / DROP / JUMP relabels), menu, and the moves.
